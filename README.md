# Digital Marketing Services Platform

## Overview

The Digital Marketing Services Platform is a web-based application designed to connect clients with marketing and advertising solutions. Users can explore available services, submit project requirements, and interact with a professional marketing service platform through an intuitive and responsive interface.

This project was developed as part of an academic Introduction to Marketing (I.M.) course project, combining marketing concepts with practical web development techniques.

## Features

### User Authentication

* Login interface for users
* Session-based page navigation
* Login and logout functionality

### Marketing Service Platform

* Display of advertising and marketing services
* Service descriptions and information
* Interactive service selection

### Customer Inquiry System

* Contact form for potential clients
* Collection of customer and campaign information
* Advertising budget selection
* Campaign requirement submission

### Data Management

* Stores submitted inquiries using Local Storage
* Maintains customer submissions during browser sessions

### User Experience

* Responsive design for desktop and mobile devices
* Smooth scrolling navigation
* Interactive notifications (Toast Messages)
* Modern user interface with animations

## Technologies Used

* HTML5

* JavaScript
* Tailwind CSS
* Local Storage API
